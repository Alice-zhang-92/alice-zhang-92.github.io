使用说明（先看这个）
  1. 第一步必须做：粘贴 API 密钥 → 点「检测连接」→ 看到「评价接口 ✓」「语音识别 ✓」两个绿勾，再往下走。
  2. 用 Chrome 或 Edge 打开本页面。麦克风弹窗请点「允许」。
  3. 流程：粘贴原文 → 点「开始录音」，学生口译 → 点「停止」→ 自动上传并转写（约 2–5 秒）→ 点「生成评价」。
  4. 单个段落建议 1–2 分钟以内，长了审核慢也容易超出免费额度限制。
  5. 本页面可以直接双击打开使用（地址栏显示 file:// 也没问题）；若浏览器不给开麦克风，改用「或用音频文件转写」上传 mp3/m4a/wav 即可。
  6. 要发给学生用链接，才需要把这个文件上传到 GitHub Pages 之类的静态托管。
  7. 录音会通过你填的那家服务商转写免费额度通道处理；不同学校对教学数据上传的要求不同，请按你单位规定自行判断。
  8. 页面刷新后原文和转写会清空，重要内容请先复制保存（密钥会保留）。
